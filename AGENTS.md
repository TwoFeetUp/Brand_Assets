# AGENTS.md

Dit project gebruikt `CLAUDE.md` als bron van waarheid voor agent-instructies.
Lees `CLAUDE.md` in deze map voordat je bestanden toevoegt of wijzigt (manifest-regels,
naamgeving, kleur/font-sync, pre-commit hook, image_dump/video_dump-uitzonderingen).

## ⚠️ Public repo

Alles in deze repo is onmiddellijk publiek (GitHub Pages CDN). Upload alleen
goedgekeurde, public-safe content. Geen foto's zonder consent, geen vertrouwelijke
of interne content, geen bestanden met gevoelige metadata (EXIF-locatie, etc.).

## Kernregel media: Drive eerst, repo daarna

- **Ruw / onbewerkt / intern / ongereviewd** → Google Drive "Raw footage inbox":
  https://drive.google.com/drive/folders/1XJKnZS0_l7f1YKtz5s8tH-kmgMTe9JNZ
- **Goedgekeurd / public-safe / herbruikbaar** → deze repo, na review + consent +
  EXIF-strip, met een entry in `manifest.json`.

Curatie gebeurt vóór upload; dump nooit een volledige ruwe set hierheen. Volledige
uitleg in `CLAUDE.md` sectie "Media-instroom: Drive eerst, deze repo daarna".
